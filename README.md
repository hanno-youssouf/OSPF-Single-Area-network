#OSPF Single-Area Network

About This Project
This is my OSPF project. I made it using Cisco Packet Tracer.

What I Did
* I connected three routers.
* I connected three switches and three PCs.
* I configured OSPF on the routers.
* I checked the OSPF neighbors.
* I checked the routing table.
* I tested the network using ping.

Network Topology
This is my network in Packet Tracer.

OSPF Neighbors
I used this command to check the OSPF neighbors:
show ip ospf  neighbor 

Routing Table
I used this command to check the routing table:
show ip route

Ping Tests
I used ping to test the connection between the PCs.

##Project File
The Packet Tracer file is ospf-single-area-network.pkt.
